# Sistema de Reserva de Asientos de Cine (Matriz 5x5)

## Datos del Estudiante
* **Nombre:** Evelyn Cecibel Jácome Pillajo

## Objetivo del Programa
El objetivo de este programa en Python es simular un sistema básico de reservas de asientos para una sala de cine representada por una matriz de 5x5. Permite visualizar la disponibilidad de asientos, seleccionar una ubicación y actualizar el estado del asiento reservado.

## Cómo Ejecutar el Programa

### Requisitos Previos
* Tener instalado Python 3.x en el equipo.

### Pasos para la ejecución
1. Clonar o descargar el repositorio:
git clone https://github.com/evelyncecibel/POGRAMACION.git
2. Navegar hasta la carpeta del proyecto:
   cd POGRAMACION/matriz-5x5

3. Ejecutar el script con el comando:
   python reserva_cine.py
