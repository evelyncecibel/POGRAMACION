Calcular el Total de una Compra

Descripción del problema

Este proyecto resuelve un problema sencillo de la vida real mediante una función en Python. Se necesita calcular el total que debe pagar un cliente en una tienda, según el precio unitario de un producto y la cantidad de unidades que compra.

Cómo funciona
La función calcular_total(precio, cantidad) recibe el precio unitario y la cantidad comprada como parámetros.
Realiza el cálculo total = precio * cantidad.
Retorna el resultado con return.
Se llama desde el bloque principal (if __name__ == "__main__":) y el resultado se muestra en consola con print().
